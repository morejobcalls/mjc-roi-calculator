# MJC ROI Calculator

Dual-option marketing ROI calculator for Season Proof Growth sales calls.

## Local Development

```bash
npm install
npm run dev
```

## Deploy to Netlify (Recommended — Free)

1. Push this repo to GitHub
2. Go to [netlify.com](https://netlify.com) → New Site from Git
3. Connect your GitHub repo `mjc-roi-calculator`
4. Build settings are auto-detected (Vite)
5. Hit Deploy → you'll get a live URL in ~60 seconds
6. Add your custom domain in Site Settings → Domain Management

## Deploy to Vercel

```bash
npm i -g vercel
vercel
```

## Build for Production

```bash
npm run build
# Output is in /dist — upload to any static host
```
